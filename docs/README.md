## Translation Policy

- Code identifiers, API paths, environment variables, and filenames stay in
  English in both versions.
- A decision status change must be applied to both language versions in the
  same pull request.
- The English document resolves ambiguity if translations temporarily differ.
- Substantive architecture changes require updates to both versions before a
  release is tagged.

## 번역 정책

- 코드 식별자, API 경로, 환경변수, 파일명은 두 언어 모두 영어로 유지한다.
- 결정 상태를 변경할 때 같은 Pull Request에서 두 언어 문서를 함께 수정한다.
- 번역 내용이 일시적으로 다를 때는 영문 문서를 기준으로 해석한다.
- 중요한 아키텍처 변경은 릴리스 태그 전에 두 언어 문서에 모두 반영한다.
